# Digital Signal Processing (DSP) Algorithms

This repository contains MATLAB implementations of core Digital Signal Processing algorithms, built from scratch without relying on built-in functions. 

## Key Features:
* **Custom FFT/IFFT:** Implemented both Iterative (Radix-2 DIT) and Recursive Fast Fourier Transform algorithms, validated against MATLAB's standard library.
* **Digital Filtering:** Applied linear convolution and frequency-domain analysis (Magnitude Spectrum) to clean noisy analog signals.
* **Overlap-Save (OVS) Method:** Implemented the Overlap-Save algorithm for fast convolution of long signals, including performance benchmarking (Execution Time vs. Direct Convolution) across various frame sizes.

**Tools Used:** MATLAB, Signal Processing Toolbox.
